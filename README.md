# ¿Quién Fue? — Spanish Puzzle Module

## About the Project

This repository contains the Spanish puzzle module for **¿Quién Fue? — Who Is the Culprit?**, an interactive mystery-solving website developed as part of a Spanish learning project.

Players solve Spanish language challenges and explore Colombian cultural clues while investigating a fictional treasure theft.

## Features

- **Translation Challenge:** Test Spanish comprehension.
- **Vocabulary Challenge:** Learn Spanish words and their English meanings.
- **Letter Cipher:** Decode a hidden Spanish word.
- **Cultural Quiz:** Explore Colombian history and heritage.
- **Interactive Scoring:** Earn up to 100 points across four challenges.
- **Hints and Replay:** Get assistance and restart the game.

## How to Run Locally

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.

No additional packages or installations are required.

## Integration

This module can be integrated into the main ¿Quién Fue? website. The HTML, CSS, and JavaScript files can be adapted to match the main project's folder structure and navigation.
